# Ivan Stepantsov

Founder of [Certance Advisory](https://www.certance.eu), a quality engineering consultancy for regulated software. Quality Engineering Lead with 10+ years in regulated finance, life sciences, and defence systems.

I help teams in high-stakes environments trust their test coverage: which business-critical journeys are actually exercised, and where a green pipeline is hiding a gap.

## What I build

**[Certance Lens](https://github.com/Certance-CE/certance-playwright-framework)**: a Playwright + BDD test-automation framework with strict locator rules, fixture-injected setup, and web-first assertions. Open source, MIT.

**[Certance-Field](https://github.com/ivan-stepantsov/Certance-Field)**: a local-first token-efficiency and guardrail kit for GitHub Copilot.

**[The Coverage Audit](https://www.certance.eu/coverage-audit)**: a fixed-scope engagement that maps a test suite to the business journeys it is supposed to protect, and shows where it does not.
